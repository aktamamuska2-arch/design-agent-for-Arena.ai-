# Output rules
## File structure
Generate a complete file suite organized as:
```
design-name/
├── index.html          # Main entry — self-contained HTML prototype
├── styles/
│   └── main.css        # CSS custom properties, layout, animations
├── scripts/
│   └── main.js         # Interactive behaviors (tabs, modals, toggles)
└── assets/
    └── (inline SVGs, data URIs — no external images)
```

## File constraints
- **index.html**: Self-contained, semantic HTML, mobile-first responsive
- **Maximum 1000 lines** per HTML file. If the design would exceed this, simplify.
- Self-contained: no `<link rel="stylesheet">` to your own files, no `<script src="…">` to your own files.
- Permitted external resources:
  - **CSS**: Tailwind CDN (`<script src="https://cdn.tailwindcss.com"></script>`), Google Fonts
  - **JS libraries** — `cdnjs.cloudflare.com` whitelist only. Pin exact version. Approved:
    - `recharts` — data viz | `Chart.js` — charting | `d3` — visualization
    - `three.js` — 3D | `lodash.js` — utilities | `PapaParse` — CSV
- **Forbidden**:
  - Arbitrary `fetch()` / `XMLHttpRequest` to external APIs — all data inline
  - Scripts from any host other than `cdnjs.cloudflare.com`
  - Hotlinked photos from any host
- All other assets must be inline: SVG icons, CSS gradients, data URIs

## CSS custom properties (required)
Declare every load-bearing visual value as a CSS custom property on `:root`:
```css
:root {
  --color-bg:       #f8f5f0;
  --color-surface:  #ffffff;
  --color-text:     #1a1a1a;
  --color-muted:    #6b6b6b;
  --color-accent:   oklch(62% 0.22 265);
  --color-accent-2: oklch(72% 0.18 40);
  --radius-base:    0.5rem;
  --radius-lg:      1rem;
  --font-sans:      'Syne', system-ui, sans-serif;
  --font-mono:      'JetBrains Mono', monospace;
  --space-unit:     1rem;
}
```
Reference in Tailwind arbitrary-value syntax: `bg-[var(--color-accent)]`. Never hard-code hex/pixel values in Tailwind classes when a variable covers the same slot.

## Structural rules
1. Semantic landmarks: `<header>`, `<main>`, `<section>`, `<article>`, `<nav>`, `<footer>`
2. Heading hierarchy: one `<h1>`, then `<h2>` per section, `<h3>` for sub-items. Never skip levels.
3. Interactive elements: `<button>` for actions, `<a href="#">` for navigation. Never `<div onclick>`.
4. Images: no hotlinked photos. Use inline SVG or CSS gradient placeholders.
5. Alt text: every `<img>` has non-empty `alt`. Decorative SVGs get `aria-hidden="true"`.
6. No `<table>` for layout; use CSS grid or flex.
7. Responsive: mobile-first breakpoints using Tailwind's `sm:`, `md:`, `lg:` prefixes.
8. Motion: CSS `transition` / `animation` only — no JS animation loops. Keep under 300ms.

## Content rules
- No lorem ipsum. Write copy specific to the domain.
- No placeholder names like "John Doe" or "Company Name" — invent plausible, diverse names.
- Numbers and dates must be realistic (not "100%" everywhere, not "Jan 1, 2020").
- Icons: inline SVG only; use simple, recognizable symbols.
